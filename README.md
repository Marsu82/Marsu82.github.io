# Flugbahn – Webseite

Öffentliche Webseite unter **https://marsu82.github.io/** (GitHub Pages).

| Pfad | Inhalt |
|---|---|
| `index.html` | Startseite (Deutsch/Englisch) |
| `app/` | Die Web-App, Quelle für die Play-Store-App. **Nicht von Hand ändern**, wird mit `site.py` aus dem privaten Repository erzeugt |
| `.well-known/assetlinks.json` | Verknüpft die Domain mit der Android-App |
| `impressum.html`, `app/datenschutz.html` | Rechtstexte |
| `bauanleitung/` | Bauanleitung der Messgeräte (PDF) |

Einstellung: *Settings → Pages → Deploy from a branch → `main` / `(root)`*.
